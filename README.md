# 🌤 Weather App

A simple and interactive weather application that displays **real-time weather information** for any city using the [OpenWeather API](https://openweathermap.org/api).  
Built with **HTML, CSS, and JavaScript**, the app dynamically changes its **background image** based on the **current weather condition** of the selected location.

---

## ✨ Features
- **Search Weather by City** – Enter any city name to get up-to-date weather details.
- **Real-time Data** – Fetches live weather information from OpenWeather API.
- **Weather-based Backgrounds** – Automatically updates the app background to match the weather (e.g., sunny, rainy, cloudy, snowy).
- **Temperature & Conditions** – Displays temperature, weather description, humidity, and wind speed.

---

## 🛠 Tech Stack
- **HTML5** – Structure and layout.
- **CSS3** – Styling and design.
- **JavaScript (Vanilla)** – API calls and DOM manipulation.
- **OpenWeather API** – Source of real-time weather data.
